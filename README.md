# CS305Project
Artemis Financial is a financial services company that needed to improve its software security and protect sensitive information. I used OWASP Dependency-Check to identify vulnerabilities and review potential risks. Secure coding is important because it prevents attacks, protects customer information, and maintains a company's reputation. The most challenging part was understanding vulnerability reports and determining appropriate fixes. I improved security by configuring HTTPS, using a self-signed certificate, reviewing dependencies, and recommending AES-256-GCM encryption. I tested the application's functionality, confirmed HTTPS worked, and reran vulnerability scans after making changes to check for new issues. I used Java, Spring Boot, Maven, Java Keytool, OWASP Dependency-Check, and the National Vulnerability Database. In the future, I would continue using these tools and secure coding practices to assess risks and select appropriate mitigation techniques. I could show employers my vulnerability assessment, scan results, and working HTTPS application to demonstrate my software development, problem-solving, and cybersecurity skills.
